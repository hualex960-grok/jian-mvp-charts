# jian-mvp-charts

Public hosting for the trend-filter combo PNGs shown on [Jian 的试验站](https://jian-mvp.hualex960.workers.dev/).

These images are generated on the bot computer from Binance USD-M perpetual klines and uploaded to the `charts-live` release. The site reads them through `/charts/…`; they are not committed to the `jian-mvp` repository on every refresh.

Do not treat this repo as the trading system source. Indicator code lives elsewhere.
